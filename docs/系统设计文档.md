## 3. 阅读行为分析算法流程图

```mermaid
flowchart TD
    A[开始] --> B[采集阅读日志数据]
    B --> C[数据预处理]
    C --> D{数据是否有效?}
    D -->|否| E[剔除异常数据]
    E --> C
    D -->|是| F[特征提取]
    F --> G[计算阅读时长]
    F --> H[计算翻页速度]
    F --> I[计算完成率]
    G --> J[K-Means聚类]
    H --> J
    I --> J
    J --> K[确定阅读类型]
    K --> L[专注型?]
    L -->|是| M[标记为专注型]
    L -->|否| N[跳跃型?]
    N -->|是| O[标记为跳跃型]
    N -->|否| P[标记为兴趣导向型]
    M --> Q[生成兴趣标签]
    O --> Q
    P --> Q
    Q --> R[计算专注度评分]
    R --> S[保存分析结果]
    S --> T[结束]
```

## 4. 推荐算法逻辑图

```mermaid
flowchart TD
    A[开始推荐] --> B{推荐类型}
```

## 5. 核心模块时序图

### 5.1 家长查看成长报告时序图

```mermaid
sequenceDiagram
    participant P as 家长
    participant F as 前端Vue
    participant C as Controller
    participant S as Service
    participant M as Mapper
    participant DB as MySQL
    
    P->>F: 点击查看成长报告
    F->>C: GET /api/growth-reports/{childId}
    C->>C: JWT Token验证
    C->>C: 权限校验(是否为该儿童家长)
    C->>S: getGrowthReportList(childId)
    S->>M: selectByChildId(childId)
    M->>DB: SELECT * FROM growth_report
    DB-->>M: 返回报告数据
    M-->>S: List<GrowthReport>
    S->>S: 计算综合得分
    S-->>C: List<GrowthReport>
    C-->>F: JSON响应
    F->>F: 渲染成长曲线图表
    F-->>P: 展示成长报告
```

### 5.2 阅读日志提交流程时序图

```mermaid
sequenceDiagram
    participant C as 儿童端
    participant F as 前端
    participant Ctrl as Controller
    participant Svc as Service
    participant Map as Mapper
    participant DB as MySQL
    
    C->>F: 完成阅读
    F->>F: 收集阅读数据
    F->>Ctrl: POST /api/reading-logs
    Ctrl->>Ctrl: JWT验证
    Ctrl->>Svc: createReadingLog(dto)
    Svc->>Svc: 数据校验
    Svc->>Svc: 计算阅读时长
    Svc->>Map: insert(readingLog)
    Map->>DB: INSERT INTO reading_log
    DB-->>Map: 插入成功
    Map-->>Svc: 返回日志ID
    Svc-->>Ctrl: 返回结果
    Ctrl-->>F: 成功响应
    F-->>C: 提交成功提示
```

### 5.3 行为分析流程时序图

```mermaid
sequenceDiagram
    participant S as 定时任务
    participant AS as AnalysisService
    participant RM as ReadingLogMapper
    participant AM as AnalysisResultMapper
    participant DB as MySQL
    
    S->>AS: 执行定时分析任务
    AS->>RM: selectAllChildren()
    RM->>DB: SELECT DISTINCT child_id
    DB-->>RM: 儿童ID列表
    RM-->>AS: List<Long> childIds
    
    loop 每个儿童
        AS->>RM: selectByChildId(childId)
        RM->>DB: SELECT * FROM reading_log
        DB-->>RM: 阅读日志列表
        RM-->>AS: List<ReadingLog>
        
        AS->>AS: 特征提取
        AS->>AS: K-Means聚类
        AS->>AS: 确定阅读类型
        AS->>AS: 计算专注度
        AS->>AS: 生成兴趣标签
        
        AS->>AM: insertOrUpdate(result)
        AM->>DB: INSERT/UPDATE analysis_result
        DB-->>AM: 保存成功
    end
    
    AS-->>S: 分析完成
```
