# 核心算法逻辑说明文档

## 1. K-Means聚类分析算法

### 1.1 算法概述
K-Means是一种经典的无监督学习算法，用于将数据分成K个不同的簇。在本系统中，我们使用K-Means算法根据儿童的阅读行为特征将其分为三类：专注型、跳跃型、兴趣导向型。

### 1.2 特征选择
我们选择以下三个核心特征进行聚类：
- **平均阅读时长**：每次阅读的平均持续时间
- **翻页速度**：每分钟翻页次数
- **完成率**：完整阅读绘本的比例

### 1.3 算法流程

```
输入：儿童阅读行为数据集D，聚类数K=3
输出：每个儿童的阅读类型标签

1. 数据预处理
   - 标准化特征值（Z-score标准化）
   - 处理缺失值和异常值

2. 初始化聚类中心
   - 随机选择K个数据点作为初始聚类中心

3. 迭代聚类
   - 计算每个数据点到各聚类中心的欧氏距离
   - 将数据点分配到最近的聚类中心
   - 重新计算每个簇的中心点
   - 重复直到聚类中心不再变化或达到最大迭代次数

4. 类型映射
   - 根据聚类中心特征值确定类型标签
   - 高完成率 + 低翻页速度 → 专注型
   - 低完成率 + 高翻页速度 → 跳跃型
   - 中等特征值 → 兴趣导向型
```

### 1.4 代码实现要点

```java
public Map<String, Object> performKMeansClustering(List<ChildReadingStats> statsList) {
    int k = 3;
    int maxIterations = 100;
    
    List<double[]> centroids = initializeCentroids(statsList, k);
    
    for (int iter = 0; iter < maxIterations; iter++) {
        Map<Integer, List<ChildReadingStats>> clusters = new HashMap<>();
        
        for (ChildReadingStats stats : statsList) {
            int nearestCluster = findNearestCentroid(stats, centroids);
            clusters.computeIfAbsent(nearestCluster, k -> new ArrayList<>()).add(stats);
        }
        
        List<double[]> newCentroids = recalculateCentroids(clusters);
        
        if (centroidsConverged(centroids, newCentroids)) {
            break;
        }
        centroids = newCentroids;
    }
    
    return assignLabels(clusters);
}
```

## 2. 协同过滤推荐算法

### 2.1 算法概述
协同过滤是推荐系统中最经典的算法之一。本系统采用基于物品的协同过滤（Item-based CF），通过分析用户的历史阅读行为，找到与用户已读绘本相似的其他绘本进行推荐。

### 2.2 相似度计算
使用余弦相似度计算绘本之间的相似性：

```
similarity(A, B) = (Σ(rating_A * rating_B)) / (√Σrating_A² * √Σrating_B²)
```

其中：
- rating_A：用户对绘本A的阅读时长或阅读次数
- rating_B：用户对绘本B的阅读时长或阅读次数

### 2.3 算法流程

```
输入：用户u的历史阅读记录R_u，绘本库B
输出：推荐绘本列表

1. 构建用户-绘本评分矩阵
   - 使用阅读时长或阅读次数作为隐式评分

2. 计算绘本相似度矩阵
   - 对于每对绘本(i, j)，计算余弦相似度

3. 生成推荐列表
   - 对于用户u已读的每个绘本i
   - 找到与i最相似的N个绘本
   - 计算推荐得分：score(j) = Σ similarity(i,j) * rating(u,i)
   - 按得分排序，取Top-K作为推荐结果
```

### 2.4 代码实现要点

```java
public List<Book> getCollaborativeRecommendations(Long childId, int topN) {
    List<ReadingLog> userLogs = readingLogMapper.selectByChildId(childId);
    Map<Long, Double> userPreferences = buildUserPreferenceVector(userLogs);
    
    Map<Long, Double> recommendations = new HashMap<>();
    
    for (Map.Entry<Long, Double> entry : userPreferences.entrySet()) {
        Long bookId = entry.getKey();
        Double preference = entry.getValue();
        
        List<BookSimilarity> similarBooks = similarityMapper.selectByBookId(bookId);
        for (BookSimilarity sim : similarBooks) {
            Double score = recommendations.getOrDefault(sim.getTargetBookId(), 0.0);
            score += sim.getSimilarity() * preference;
            recommendations.put(sim.getTargetBookId(), score);
        }
    }
    
    return getTopNBooks(recommendations, topN);
}
```

## 3. 专注度计算算法

### 3.1 算法概述
专注度是衡量儿童阅读质量的重要指标。本系统通过多个维度的数据综合计算专注度评分。

### 3.2 计算维度

| 维度 | 权重 | 说明 |
|------|------|------|
| 平均单页停留时间 | 30% | 停留时间适中表示专注阅读 |
| 翻页速度稳定性 | 25% | 稳定的翻页速度表示持续专注 |
| 阅读完成率 | 25% | 完成阅读表示持续关注 |
| 阅读时长 | 20% | 较长的阅读时长表示兴趣浓厚 |

### 3.3 计算公式

```
专注度得分 = w1 * S1 + w2 * S2 + w3 * S3 + w4 * S4

其中：
S1 = 标准化(平均单页停留时间) * 100
S2 = (1 - 标准化(翻页速度标准差)) * 100
S3 = 完成率 * 100
S4 = 标准化(阅读时长) * 100

w1 = 0.30, w2 = 0.25, w3 = 0.25, w4 = 0.20
```

### 3.4 代码实现要点

```java
public double calculateFocusScore(Long childId) {
    List<ReadingLog> logs = readingLogMapper.selectByChildId(childId);
    
    double avgPageTime = calculateAveragePageTime(logs);
    double pageSpeedStability = calculatePageSpeedStability(logs);
    double completionRate = calculateCompletionRate(logs);
    double avgReadingTime = calculateAverageReadingTime(logs);
    
    double s1 = normalize(avgPageTime, 10, 60) * 100;
    double s2 = (1 - normalize(pageSpeedStability, 0, 10)) * 100;
    double s3 = completionRate * 100;
    double s4 = normalize(avgReadingTime, 5, 30) * 100;
    
    return 0.30 * s1 + 0.25 * s2 + 0.25 * s3 + 0.20 * s4;
}

private double normalize(double value, double min, double max) {
    return Math.max(0, Math.min(1, (value - min) / (max - min)));
}
```

## 4. 兴趣标签生成算法

### 4.1 算法概述
根据儿童的阅读历史，自动生成兴趣偏好标签。

### 4.2 计算方法

```
对于每个绘本类别C：
1. 计算该类别的阅读时长占比
2. 计算该类别的阅读次数占比
3. 计算该类别的重复阅读率

兴趣得分(C) = 0.4 * 时长占比 + 0.3 * 次数占比 + 0.3 * 重复阅读率

如果兴趣得分 > 阈值(0.15)，则生成该类别标签
```

## 5. 成长趋势预测算法

### 5.1 算法概述
基于历史成长数据，预测儿童未来的阅读成长趋势。

### 5.2 预测方法
使用线性回归模型进行趋势预测：

```
y = a * x + b

其中：
y：预测的成长维度得分
x：时间周期
a：成长斜率（由历史数据拟合得出）
b：基准得分
```

### 5.3 预测步骤

1. 收集最近4周的成长数据
2. 对每个维度分别进行线性回归
3. 计算回归系数a和b
4. 预测未来2周的得分
