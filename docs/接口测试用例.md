# 接口测试用例

## 1. 认证接口

### 1.1 用户登录
- **接口地址**: POST /api/auth/login
- **请求参数**:
```json
{
  "username": "admin",
  "password": "admin123",
  "remember": true
}
```
- **预期结果**: 返回JWT令牌和用户信息
- **测试用例**:
  - 正确用户名密码登录 → 成功
  - 错误密码登录 → 失败
  - 用户名不存在 → 失败
  - 空用户名或密码 → 参数校验失败

### 1.2 获取用户信息
- **接口地址**: GET /api/auth/info
- **请求头**: Authorization: Bearer {token}
- **预期结果**: 返回当前登录用户信息

### 1.3 用户登出
- **接口地址**: POST /api/auth/logout
- **预期结果**: 清除登录状态

## 2. 用户管理接口

### 2.1 获取用户列表
- **接口地址**: GET /api/users
- **请求参数**: page=1, size=10, username=, role=
- **预期结果**: 返回分页用户列表
- **权限要求**: ADMIN

### 2.2 创建用户
- **接口地址**: POST /api/users
- **请求参数**:
```json
{
  "username": "testuser",
  "password": "123456",
  "realName": "测试用户",
  "phone": "13800138000",
  "role": "PARENT"
}
```
- **预期结果**: 创建成功返回用户ID
- **权限要求**: ADMIN

### 2.3 更新用户
- **接口地址**: PUT /api/users/{id}
- **预期结果**: 更新成功

### 2.4 删除用户
- **接口地址**: DELETE /api/users/{id}
- **预期结果**: 删除成功
- **权限要求**: ADMIN

## 4. 绘本管理接口

### 4.1 获取绘本列表
- **接口地址**: GET /api/books
- **请求参数**: page=1, size=10, title=, category=, difficulty=
- **预期结果**: 返回分页绘本列表

### 4.2 创建绘本
- **接口地址**: POST /api/books
- **请求参数**:
```json
{
  "title": "小熊维尼",
  "author": "A.A. Milne",
  "category": "animal",
  "subCategory": "land",
  "difficulty": "easy",
  "pageCount": 24,
  "description": "小熊维尼的故事..."
}
```
- **预期结果**: 创建成功
- **权限要求**: ADMIN

### 4.3 批量导入绘本
- **接口地址**: POST /api/books/upload
- **请求类型**: multipart/form-data
- **请求参数**: file (Excel文件)
- **预期结果**: 导入成功返回导入数量
- **权限要求**: ADMIN

### 4.4 按分类获取绘本
- **接口地址**: GET /api/books/category
- **请求参数**: category=animal, subCategory=land
- **预期结果**: 返回指定分类的绘本列表

## 9. 权限测试用例

### 9.1 家长权限测试
- 只能查看自己绑定的孩子信息
- 只能查看自己孩子的阅读记录
- 只能查看自己孩子的成长报告
- 不能访问用户管理功能
- 不能访问班级管理功能

### 9.2 教师权限测试
- 可以查看本班所有儿童信息
- 可以查看本班阅读统计数据
- 不能查看其他班级数据
- 不能管理用户

### 9.3 管理员权限测试
- 可以访问所有功能
- 可以管理所有用户
- 可以管理所有绘本
- 可以查看系统统计

---

## 10. 异常测试用例

### 10.1 参数校验
- 空必填参数 → 400错误
- 参数格式错误 → 400错误
- 参数超出范围 → 400错误

### 10.2 认证授权
- 未登录访问 → 401错误
- Token过期 → 401错误
- 权限不足 → 403错误

### 10.3 资源不存在
- 用户不存在 → 404错误
- 绘本不存在 → 404错误
- 儿童不存在 → 404错误

### 10.4 业务异常
- 重复绑定孩子 → 业务异常
- 删除有关联数据的用户 → 业务异常
